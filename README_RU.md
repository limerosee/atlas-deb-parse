# ATLAS SteamOS Updater

[English version](README.md)

Специализированный помощник для установки обновлений ATLAS в SteamOS. Он
перехватывает открываемое ATLAS обновление в формате `.deb`, проверяет пакет и
устанавливает только разрешённые файлы в существующий Fedora Distrobox с именем
`atlas`.

Он **не изменяет** доступную только для чтения файловую систему SteamOS и не
исправляет и не заменяет код обновления ATLAS.

Этот инструмент предназначен исключительно для ATLAS. Он не является пакетным
менеджером или универсальным слоем совместимости с Debian. Проект независим и
не связан с ATLAS и не одобрен его разработчиками. Репозиторий не содержит
исходный код, бинарные файлы, ресурсы, архивы пакетов, учётные данные или
пользовательские настройки ATLAS.

## Модель безопасности

Инструмент принимает только:

- обычный файл `.deb`, не являющийся символической ссылкой и расположенный в
  `~/.local/share/com.nanitnet.atlas/updates`;
- Debian-пакет `atlas` для архитектуры `amd64`;
- обычные файлы пакета в известных каталогах ATLAS под `/usr/bin` и
  `/usr/lib/ATLAS`, а также в точных расположениях desktop-файла и значков;
- файлы, содержимое которых соответствует метаданным `md5sums` пакета.

Перед установкой отображается полный SHA-256 пакета и запрашивается
подтверждение. Скрипты `preinst`, `postinst`, `prerm` и `postrm` никогда не
запускаются. Вместо этого инструмент самостоятельно выполняет единственное
известное необходимое действие после установки: назначает и проверяет
`cap_net_admin,cap_net_raw+ep` для двух сетевых компонентов.

ATLAS проверяет подписанный манифест обновления до помещения пакета в каталог
обновлений. Этот инструмент не может независимо повторить такую проверку,
поскольку открытый ключ, отсоединённый манифест и подпись не сохраняются рядом
с `.deb`. Его независимыми мерами защиты являются ограничение расположения,
проверка метаданных пакета, список разрешённых файлов, хеши и подтверждение
пользователя.

## Требования

- SteamOS в режиме рабочего стола
- Distrobox-контейнер с именем `atlas`
- Python 3 на хосте и в контейнере
- Fedora-пакеты `binutils`, `zstd` и `libcap` в контейнере
- `xdg-mime` на хосте

Внутри контейнера выполните:

```bash
sudo dnf install -y binutils zstd libcap
```

## Установка

Распакуйте проект в домашний каталог и выполните на хосте SteamOS:

```bash
chmod +x install.sh uninstall.sh src/*.py
./install.sh
```

Установщик сохраняет предыдущий обработчик MIME для `.deb` и назначает
`atlas-steamos-updater.desktop` обработчиком Debian-пакетов.

Когда ATLAS скачивает и открывает обновление, появляется окно терминала.
Инструмент показывает версию пакета и SHA-256, запрашивает подтверждение,
предлагает закрыть ATLAS, запрашивает пароль `sudo` контейнера, устанавливает
обновление, восстанавливает capabilities и предлагает снова запустить ATLAS.

Пакеты вне собственного каталога обновлений ATLAS отклоняются.

## Резервные копии и откат

Перед заменой файлов установщик контейнера сохраняет существующие файлы в:

```text
/var/lib/atlas-steamos-updater/backups/
```

Если установка или проверка capabilities завершается ошибкой, сохранённые
файлы восстанавливаются автоматически. Резервные копии успешных установок
сохраняются для ручного отката и аудита. Версия, хеш и путь к резервной копии
последнего установленного обновления записываются в:

```text
~/.local/state/atlas-steamos-updater/atlas.json
```

## Удаление

```bash
./uninstall.sh
```

По возможности восстанавливается ранее сохранённый обработчик MIME. Резервные
копии и данные состояния намеренно сохраняются.
